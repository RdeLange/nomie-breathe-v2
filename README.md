# Nomie Breathe v2

Guided breathing with a circle that grows and shrinks, a dot that goes round each breath, and your own breathing exercises. Logged to Nomie.

Source: https://github.com/RdeLange/nomie-breathe-v2. Pages: https://dailynomie.github.io/nomie-breathe-v2/

## Commands

    npm install
    npm test
    npm run build
